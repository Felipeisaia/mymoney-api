# 💰 MyMoney - Gerenciador de Finanças Pessoais

O **MyMoney** é uma aplicação Full Stack desenvolvida para auxiliar no controle financeiro, permitindo o cadastro de entradas e saídas e visualização de métricas através de gráficos intuitivos.



## 🚀 Demonstração
Você pode acessar a aplicação online aqui: **https://mymoney-api-delta.vercel.app/**

## 🛠️ Tecnologias Utilizadas

### Front-end
- **React** (v19) com **Vite**
- **TypeScript**
- **Styled Components** (Estilização)
- **Recharts** (Gráficos)
- **React Toastify** (Notificações)
- **Axios / Fetch API** (Consumo de dados)

### Back-end
- **Node.js** com **Fastify**
- **Prisma ORM**
- **SQLite / PostgreSQL**
- **TypeScript**
